# Mega Drive

> Полная инструкция по шагам, от магазина до сборки из исходников и памяти CYD, — в
> [docs/mega-drive.ru.md](../mega-drive.ru.md) ([English](../mega-drive.md)).

`MD.AXE` — эмулятор Sega Mega Drive (Genesis) для ArgonOS. Он показывает
список игр на карте, ставит игру на паузу с сохранением и загрузкой
состояния, играет звук и понимает 3- и 6-кнопочный джойстик. Ядро — gwenesis
и Musashi (68000); подробности устройства — в
[apps/md/README.md](../../apps/md/README.md).

## Какие платы

Одна программа, два образа — под чип:

| Чип | Образ | Плата, на которой проверено | Скорость (замер) |
|---|---|---|---|
| ESP32 без PSRAM | `esp32` | CYD (ESP32-2432S028R), экран ILI9341 320×240, карта | Sonic — 54–60 кадров эмуляции в секунду, на экран ~15 кадров в секунду; The Lost Vikings — 52–58 |
| ESP32-S3 с PSRAM | `esp32s3` | ESP32-S3-CAM с экраном ST7789 | Alex Kidd — 59 кадров эмуляции, на экран 30–58 |

Цифры сняты на разных играх и сценах, поэтому платы между собой по ним не
сравнить. Кадров эмуляции в секунду — то, с какой скоростью идёт игра (60 —
как на приставке); на экран уходят только изменившиеся строки, поэтому
кадров на экране меньше, особенно в насыщенных сценах.

Обе сборки — одна и та же программа: второе ядро рисует картинку, Z80 и
звуковые чипы работают там же, картридж читается прямо из flash.

На плате с PSRAM экран обновляется **целым кадром**: оба ядра рисуют кадр в
один из двух буферов в PSRAM, и только готовый кадр уходит на экран — отдельным
потоком, пока следующий рисуется во второй буфер. Без PSRAM (CYD) кадр
отправляется по строкам по мере рисования; в быстрых сценах там видны полосы.
Память машины, которой не хватило во внутренней, сборка для S3 тоже берёт из
PSRAM; внутренняя память остаётся системе, радио и драйверу телефонного
джойстика, а карта не отключается на время игры.

## Установить из магазина

Программа **MD** есть в магазине приложений ArgonOS:
<https://170-168-150-42.sslip.io>.

1. Если на плате ещё нет ArgonOS — «Установить ArgonOS» в шапке магазина:
   страница сама прошьёт плату по USB из браузера (Chrome или Edge) и
   подключит её к Wi-Fi. В этой прошивке уже есть клиент магазина.
2. «Мои платы» → добавьте плату. Плата спросит на своём экране, согласны ли вы
   стать её владельцем.
3. Откройте **MD** в каталоге и установите на свою плату. Магазин сам выберет
   образ под чип платы. Программа ляжет в каталог программ: на карту, если
   она вставлена, иначе в `C:\APPS`.

Дальше — [запуск](#запуск) и [игры](#игры).

## Собрать самому

Нужно то же, что для самой системы: ESP-IDF 5.5 и Python (см. корневой
[README](../../README.md)). Из корня репозитория, в PowerShell:

```powershell
.\apps\md\build.ps1 -Chip esp32      # CYD и другие ESP32
.\apps\md\build.ps1 -Chip esp32s3    # ESP32-S3 с PSRAM
```

Образ — `build\md\<чип>\MD.AXE`, около 480 КБ. Компилятор выбирается по
чипу: у ESP32 (LX6) нет части команд S3 (LX7), и образ для S3 упадёт на CYD
на первой же такой команде.

### Прошивка для CYD

MD на CYD идёт на прошивке **без Wi-Fi**: с радио игре не хватает памяти
(«md: short of memory»).

```powershell
.\argon.cmd target esp32-cyd
.\argon.cmd build
.\argon.cmd flash -p COM16          # свой порт
```

Подробнее о плате — [09-esp32-cyd.md](../09-esp32-cyd.md). Для S3-CAM цель
`esp32s3-cam`, плата описана в [14-esp32-s3-cam.md](../14-esp32-s3-cam.md).

### Положить на плату

Проще всего — картридером: `MD.AXE` и игры в корень карты, карту в плату.
Без карты (S3-CAM) — на `C:` по сети, как любой файл:
[04-network.md](04-network.md).

## Запуск

```
A:\> run a:\md.axe                    окно со списком игр
A:\> run a:\md.axe a:\sonic.swp       сразу игра (только .SWP, см. «Игры»)
```

В окне: стрелки — выбор, A, C или Start — открыть, B — папка выше, Esc
(MENU) — выйти.

**Меню паузы** — Esc, Start+Mode на 6-кнопочном джойстике, кнопка MENU
телефонного джойстика или касание экрана (у CYD экран сенсорный): RESUME,
SAVE STATE, LOAD STATE, LOAD GAME (другая игра), EXIT. Состояние сохраняется
рядом с игрой; на CYD — в `C:\`, потому что карта на время игры отключена.

## Игры

Образы картриджей `.BIN`, `.MD` или `.GEN`, **распакованные** — ZIP MD не
открывает. При первом запуске MD переставляет байты образа под процессор
платы и кладёт рядом файл `.SWP`; дальше он открывает уже его. Эта перестановка
на плате идёт заметное время — можно сделать её заранее на компьютере
(`python tools\mdrom.py игра.bin`; он же переводит `.SMD`), а можно просто
подождать один раз. Из командной строки MD открывает файл как есть — там нужен
`.SWP`.

## Управление

| Клавиша | Кнопка Mega Drive |
|---|---|
| стрелки | крестовина |
| Z X C | A B C |
| Enter | Start |
| A S D | X Y Z |
| M | Mode |
| Esc | меню паузы |

Клавиатура — любая, что есть у платы: консоль по кабелю (терминал на
компьютере) или USB- и Bluetooth-клавиатура там, где плата их поддерживает.

### Джойстик Sega (PCF8574)

Настоящий 3- или 6-кнопочный джойстик подключается через расширитель
PCF8574 на шине I2C, драйвер — `SEGAPAD.SYS`:
`.\argon.cmd apps --only SEGAPAD.SYS` собирает его под чип текущей цели
(`argon target`), образ — `build\apps\SEGAPAD.SYS`.

| PCF8574 | Разъём джойстика (DB9) | Сигнал |
|---|---|---|
| P0 | 1 | вверх |
| P1 | 2 | вниз |
| P2 | 3 | влево |
| P3 | 4 | вправо |
| P4 | 6 | A / B |
| P5 | 9 | Start / C |
| P6 | 7 | SELECT |
| — | 5 | 3,3 В |
| — | 8 | земля |

Шина — в `C:\SYSTEM.CFG` (на CYD это разъём CN1, выводы IO21 и IO22):

```
[i2c0]
sda = 21
scl = 22
khz = 100
pullups = true
```

Затем, до запуска MD:

```
A:\> drv load a:\segapad.sys
```

Драйвер сам находит PCF8574 на адресах 0x20–0x27 и сам понимает, 3 у
джойстика кнопки или 6. Кнопка **Mode** уходит в игру (её использует, например,
The Lost Vikings); меню — **Start и Mode вместе**. Проверено на CYD; на S3 —
нет. Для опытов без джойстика есть подставка на ESP-07, которая притворяется
PCF8574 и даёт кнопки со страницы в телефоне:
[firmware/esp8266-segapad](../../firmware/esp8266-segapad/README.md).

### Телефон как джойстик

На плате с Wi-Fi и PSRAM (S3-CAM): `drv load c:\phone.sys`, затем на телефоне
страница `http://<адрес платы>:8765/#pad`. Подробности —
[apps/phone/README.md](../../apps/phone/README.md). На CYD во время игры не
работает: Wi-Fi и драйвер займут память, которая нужна игре.

## Ключи запуска

После имени игры, через пробел:

| Ключ | Что |
|---|---|
| `pad3` | 3-кнопочный джойстик вместо 6-кнопочного — для старых игр, которых он смущает |
| `stats` | каждые 2 секунды: кадров в секунду, время кадра, сколько ушло на экран |
| `fps30` | рисовать каждый второй кадр (эмулируются все 60) |
| `sndhere` | Z80 и звук на том же ядре, что и игра: медленнее, зато Z80 идёт вровень с игрой — для игры, которая ждёт от него ответа |
| `nosound` | без звука |

Полный список — в [apps/md/README.md](../../apps/md/README.md).

## Если что-то не так

- **Чёрный экран, а игра будто идёт** (`stats` показывает 59 кадров, а на
  экран не уходит ни строки): игра ждёт чего-то от машины. Так было с
  The Lost Vikings — она ждала программу, которую сама загрузила в Z80.
  Попробуйте `sndhere`, и напишите нам, с какой игрой.
- **«md: short of memory»** на CYD: прошивка с Wi-Fi или загружено слишком
  много драйверов. Нужна `esp32-cyd`, из драйверов — только экран, касание и
  джойстик.
- **Падение «illegal instruction»** сразу после запуска: образ не для этого
  чипа — `esp32s3` на ESP32 или наоборот.
- **После выхода из MD нет карты** (`file not found`): `mount a:`.
