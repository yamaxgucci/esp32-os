# Графическая оболочка

Рабочий стол в стиле Windows 3.11: окна, папки, файлы, мышь. Загружаемое
приложение, а не часть прошивки — ядро об оболочке не знает.

```
C:\>run c:\desktop.axe
```

Нужны дисплей и указатель. Без дисплея оболочка так и скажет и выйдет; без
указателя работать можно с клавиатуры, но неудобно — стол про мышь.

## Что на экране

**Строка меню** сверху: `File`, `Window`, `Help`. **Значки дисков** на столе —
только те, что действительно смонтированы: карты нет — значка `A:` нет. Внизу
**строка состояния** с координатами указателя и счётчиками — она диагностическая
и останется до тех пор, пока стол не измерен на плате.

Двойной щелчок по значку диска открывает **окно папки** на его корне: список со
значками, именами и размерами, полоса прокрутки, внизу — сколько объектов и
сколько байт. Двойной щелчок по каталогу входит в него, по `..` — выходит.
Двойной щелчок по программе её запускает.

## Клавиши

| Клавиша | Что делает |
|---|---|
| `F8` | копировать выделенное |
| `F7` | переместить или переименовать |
| `F2` | переименовать на месте |
| `Delete` | удалить, с подтверждением |
| `F5` | перечитать каталог; на столе — перерисовать экран |
| стрелки, `PgUp`/`PgDn`, `Home`/`End` | по списку |
| `Enter` | открыть выделенное |
| `Backspace` | на каталог выше |
| `F10` | встать на строку меню; дальше стрелки, `Enter`, `Esc` |
| `Ctrl+Tab` | следующее окно |
| `Ctrl+F4` | закрыть активное окно |
| `Alt+F4` | выйти из оболочки (спросит) |

**`Alt+Tab` и `Alt+1..4` оболочке не принадлежат** — их забирает супервизор для
слотов сессий, и забирает раньше, чем приложение их увидит. Поэтому окна
переключаются `Ctrl+Tab`, а закрываются `Ctrl+F4`: в Windows 3.11 это были ровно
те же сочетания для окон *внутри* приложения.

## Мышь

Тянуть за заголовок — переместить окно; за край или угол — изменить размер.
Двойной щелчок по заголовку — развернуть и обратно. Кнопки в заголовке:
системная (закрыть), свернуть, развернуть. Свёрнутое окно становится плиткой
внизу стола, двойной щелчок по плитке возвращает его.

Окно тянется **контуром**, а не телом. Это не стилизация: по проводу к
внешнему экрану движущаяся картинка стоит 3.5 кадра в секунду, и тащить окно
телом — значит это увидеть.

**Значок диска можно перетащить** куда угодно на столе, и он там останется —
положение записывается в `DESKTOP.INI`. `Window > Arrange icons` возвращает все
в столбец слева.

## Файловые операции

Копировать, переместить, переименовать, удалить, создать каталог — из меню
`File` или клавишами выше. Это те же операции, что у файлового менеджера `fm`:
одно ядро на двоих, чтобы «файл занят» и «место кончилось» не значили в двух
местах разного.

Куда копировать — вводом строки. **Имя без каталога значит «рядом с
исходным»**: выделили `hello.axe`, `F8`, набрали `hello2.axe` — получилась копия
в том же каталоге. Путь, который **существует и является каталогом**, значит «в
него, под тем же именем».

Каталог копируется и удаляется целиком. Перед копированием каталога он
обходится, чтобы полоса прогресса что-то значила — на время обхода в окне
написано `Counting`, и `Esc` его прерывает. У отдельного файла размер известен
сразу, и обход не нужен.

`Esc` останавливает операцию. Что уже скопировано — остаётся; **недописанный
файл удаляется, а не остаётся обрезанным**: файл с правильным именем и
неправильным содержимым — худший из исходов. Прерванное перемещение оставляет
источник на месте.

`F2` переименовывает **на месте**: путь с разделителем отвергается, потому что
переименование, которое молча перенесло файл в другой каталог, — не то, о чём
просили. Для этого есть `F7`.

## Запуск программ

Двойной щелчок по `.AXE`, или `File > Run...`. Оболочка отпускает дисплей,
программа владеет всем экраном, по выходе стол возвращается и
перерисовывается. Консольная программа печатает на экран и ждёт клавиши, чтобы
вывод можно было прочесть; графическая забирает экран и отдаёт его, когда сама
решит.

Чем программа кончилась, оболочка говорит всегда — программа, которая ничего не
печатает, иначе не оставляет следа, что вообще запускалась.

`[assoc]` из `SYSTEM.CFG` работает и здесь: `Enter` на `.txt` откроет то, что
там назначено — см. [../03-board-config.md](../03-board-config.md).

## Свойства

`File > Properties...` — про то, что выделено:

* **файл**: имя, тип, размер, дата, флаги;
* **диск**: файловая система, всего, свободно, точка монтирования. Чтобы
  спросить про диск, щёлкните по его значку один раз (это выделение) и закройте
  или уберите с него окна — окно папки впереди значка, и вопрос тогда про файл
  в нём.

**«Дата не записана» — это правда, а не ошибка.** littlefs хранит время
изменения необязательным атрибутом, и у файлов, попавших на `C:` из образа,
его нет. Плата, которая никогда не видела SNTP-сервера, к тому же считает, что
сейчас 1970 год — см. `date sync` в [01-shell.md](01-shell.md).

## `DESKTOP.INI`

Стол запоминает, как его оставили, в `C:\DESKTOP.INI` — обычный INI, который
можно прочитать, поправить и удалить; удалить — это и есть способ вернуть всё к
исходному.

```ini
[desktop]
background = 0x008080
dblclick   = 400

; куда перетащили значок каждого диска
[icons]
C: = 4,4
T: = 272,160

; x,y,w,h,состояние,путь — путь последним, чтобы в нём могли быть запятые
[windows]
1 = 8,26,280,170,0,c:\
```

| Ключ | Значение |
|---|---|
| `background` | цвет стола, `0xRRGGBB` |
| `dblclick` | сколько миллисекунд между щелчками ещё считается двойным щелчком; `100`..`2000` |
| `[icons]` | буква диска = положение его значка, в пикселях от левого верхнего угла рабочей области |
| `[windows]` | какие каталоги были открыты, в каких окнах и какого размера; состояние `0` обычное, `1` свёрнуто, `2` развёрнуто |

Пишется **при выходе и после перемещения значка**. Что **не** запоминается
сознательно: какое окно было сверху, где стоял курсор в списке и куда список
был прокручен. Всё три — про момент, а не про расположение, и восстановленный
курсор в каталоге, содержимое которого с тех пор изменилось, встанет на другой
файл, а не на тот, на котором стоял.

Окна восстанавливаются в том же порядке; каталог, которого больше нет,
пропускается молча — карта, которая была в слоте в прошлый раз и не в этот, это
обычное дело, а оболочка, которая начинается с окна сообщения об этом, — это
оболочка, которую надо закрыть, прежде чем ею пользоваться.

## Запускать при загрузке

`AUTOEXEC.BAT` на `C:` выполняется после загрузки:

```
run c:\desktop.axe
```

Стол займёт слот сессии 1. `Ctrl+\` уводит в системный шелл, если нужно
добраться до командной строки, не выходя из стола.
